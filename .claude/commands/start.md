Kamu memulai sesi baru pada proyek RantaiNaik. Kamu tidak punya ingatan sesi sebelumnya. Semua konteks ada di repo.

1. Baca `AGENTS.md`, `docs/HANDOFF.md`, dan `docs/DECISIONS.md`.
2. Jalankan `git status`, `git branch --show-current`, `git log -10 --oneline`, dan `git diff --stat`.
3. Bandingkan `HANDOFF.md` dengan kondisi repo. Bila ada perubahan belum di-commit atau branch `wip/*`, laporkan.
4. Baca `docs/spec/README.md`, lalu hanya file spec yang relevan dengan bagian "Berikutnya" di `HANDOFF.md`.
5. Ringkas maksimal 10 baris: status, tugas berikutnya, file spec yang dibaca, serta ketidaksesuaian atau risiko.
6. Tunggu konfirmasi saya sebelum menulis kode.
