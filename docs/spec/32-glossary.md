## 18. Glosarium
| Istilah | Arti |
|---|---|
| **Konveksi** | Usaha produksi pakaian jadi skala kecil-menengah |
| **Maklon (makloon)** | Produksi pesanan atas nama brand pemesan oleh pihak lain |
| **CMT** | *Cut, Make, Trim*: jasa potong dan jahit, bahan disediakan pemesan |
| **Full package** | Produksi lengkap termasuk pengadaan bahan oleh pemasok |
| **Tech pack** | Dokumen spesifikasi teknis produk (gambar teknis, bahan, ukuran, konstruksi) |
| **Size breakdown / rincian ukuran** | Pembagian jumlah pesanan per ukuran |
| **Gramasi (gsm)** | Berat kain per meter persegi (gram per m²) |
| **Bordir / sablon / DTF** | Teknik dekorasi: sulam, cetak sablon, cetak langsung ke kain |
| **Pola dan grading** | Pola potongan dan penyesuaian pola untuk beragam ukuran |
| **Sampel pra-produksi** | Contoh produk yang dinilai pembeli sebelum produksi massal |
| **AQL** | *Acceptable Quality Limit*: batas cacat yang masih dapat diterima pada inspeksi sampling |
| **Rework** | Perbaikan produk yang tidak lolos QC |
| **RFQ / PO / MOQ** | *Request for Quotation* / *Purchase Order* / *Minimum Order Quantity* |
| **NIB / TKDN** | Nomor Induk Berusaha / Tingkat Komponen Dalam Negeri |
| **Readiness Score** | Skor kesiapan UMKM menjadi pemasok industri (0-100) |
| **Addendum** | Perubahan resmi atas RFQ setelah dipublikasikan |
| **Rule-based** | Berbasis aturan eksplisit, bukan model yang dilatih |
| **Broker** | Perantara yang mempertemukan dua pihak dan mengelola prosesnya tanpa menjadi pihak yang memproduksi atau membeli |
| **Lot** | Bagian dari satu RFQ yang dikerjakan satu UMKM pemenang (mis. 50 dari 200 pcs) |
| **Split award** | Pembagian satu RFQ ke beberapa UMKM pemenang, satu per lot |
| **Golden sample / standar acuan** | Sampel atau spesifikasi terkunci yang menjadi acuan mutu bersama semua lot |
| **Order induk / sub-order** | Wadah satu RFQ yang dibagi / pesanan per lot per UMKM |
| **Backup / runner-up** | Penawar pengganti pada sebuah lot bila pemenang mundur atau gagal |
| **Escrow (rekening bersama, rekber)** | Penitipan dana pada pihak ketiga yang dirilis ketika syarat terpenuhi |
| **Rilis / refund** | Pencairan dana ke UMKM / pengembalian dana ke pembeli |
| **Sengketa (dispute)** | Perselisihan pada order yang diputus admin berdasarkan bukti |
| **Komisi (take rate)** | Persentase nilai order yang diterima platform |
| **Kapasitas terpakai** | Komitmen kapasitas UMKM dari penawaran aktif dan order berjalan |
